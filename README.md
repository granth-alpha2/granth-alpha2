# ⚙️ Setup: Making the Cards Self-Updating

The GitHub Summary, Programming Languages, Streak, and Snake sections above are all generated by **one GitHub Action** and committed straight into this repo as static SVGs — no live API calls when someone views your profile, so nothing can go down or hit a rate limit.

**One-time setup:**
1. In this repo, go to **Settings → Actions → General → Workflow permissions**, select **"Read and write permissions"**, and save.
2. Add the file `.github/workflows/profile-readme.yml` (provided separately) to this repository.
3. Go to the **Actions** tab → select **"Update Profile README Assets"** → click **"Run workflow"** to trigger it the first time.
4. After it finishes (~1–2 minutes), the images above will resolve to files under `readme-assets/` in this repo and render correctly.

It will then re-run automatically every day at 03:00 UTC to keep everything fresh.
